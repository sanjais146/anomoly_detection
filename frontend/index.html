    Causal Information Availability Analysis E13 Ablation

    Label Delay vs. Validation F1

    Key finding: Reducing Δ from 7 days → 0 days inflates F1 by 15.2pp (59.78% → 74.98%). Δ=0 is not deployment-realistic — real chargebacks take days to process. This explains the gap with external benchmarks that may use 0-day or transductive protocols.

    E11/E14 Continual Learning (Validation Only)

    These are VALIDATION results — not Test scores. E14 did not reach the +1.5pp robustness gate required to unfreeze the Test set. E10 remains authoritative.

    Research Contribution — Why This Project Matters

    1. Causal Evaluation Protocol
    Enforces a 7-day label-availability boundary simulating real-world chargeback delays. Proves that standard evaluations often violate temporal causality.
    2. Information Availability Ablation
    E13 demonstrates that collapsing Δ from 7→0 days inflates F1 by 15pp. This provides a principled explanation for the gap between causal and benchmark evaluations.
    3. Deployment Realism
    E10 achieves 62.25% Test F1 under strictly chronological inductive evaluation — a defensible, reproducible result for real-world e-commerce anomaly detection.
    Under the project's defined causal protocol, E10 achieves 62.25% Test F1. The published GNN-EADD (73%) benchmark is not directly comparable — it evaluates a different dataset using a transductive node classification protocol. We do not claim to beat the benchmark, nor that 62.25% is the absolute ceiling of the dataset.
